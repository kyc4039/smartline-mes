# modules

화면과 API를 기능별로 나눈 Flask 블루프린트입니다. `app.py`가 모두 등록합니다.

| 파일 | 기능 |
|---|---|
| core.py | 관제 대시보드 · 디지털 트윈 · 생산 · OEE 등 공통 페이지와 상태 API |
| gate.py | ① 안전게이트: 보호구 3종 확인 후 입장 |
| safety.py | ② 프레스 안전: 위험구역 침입 시 안전 정지 · 재가동 |
| quality.py | ③ 품질검사: 캔 불량 판정 |
| maintenance.py | ④ 설비보전: 고장 메모 분류 · 정비 티켓 |
