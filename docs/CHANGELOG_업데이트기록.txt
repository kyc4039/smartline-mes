[10/07 밤 · 검사기 정지 방식] — 상자가 비전 검사기에서 5초 멈춰 검사, 그 안에 불량이 감지되면 그 상자가 불량
  - 라인 투입 = 6초에 1개 (검사 5초 + 다음 상자 이동 1초). 불량 1개 = 양품 1개 감소 → 트럭이 그만큼 늦게 출발
  - 검사기 위 '🔍 검사 중 2.5 / 5초' → '■ 불량 · 찌그러짐' / '● 정상' (관제 대시보드 모니터도 같음)
  - 회색 상자 = 아직 검사 기록이 없는 상자. 검사가 끝나는 순간 번호(#id)가 붙음
  - 시뮬레이터는 5초 동안 불량이 없으면 검사 끝 순간에 '정상' 1건 기록 (기록 수 = 투입 수)
  - 시연 버튼: 불량(흠집 · 찌그러짐) = 지금 검사 중인 상자가 불량 / 불량 6연속 = 다음 6개가 차례로 불량
              팔레트 · 검사 10개 · 트럭 출발 = 라인 ×8 빨리감기 / 속도 ×3 = 라인 ×3 1분
  - config.py에 넣으면 좋은 값:
      TARGET_CYCLE_SEC = 5.0     # (4.0이 적혀 있어도 자동으로 5초로 계산하지만 맞춰 두면 헷갈리지 않음)
      INSPECT_SEC = 4.0          # 검사기 정지 시간 (10/07 밤 2: 4초)
      TRUCK_PALLETS = 7          # 5초 택트에서 트럭 1대 약 4분 45초 (발표 날은 4 → 약 2분 45초)
  - 오늘 이미 쌓인 기록(예전 4초 방식)은 장부가 빠른 검사로 따라잡아 정리함 (DB는 그대로)
  - 이번에 바꾼 파일 백업: backups/*.1007takt

[10/07 저녁 · 제품 흐름 새 설계 (FLOW_V2)] — 검사 기록 1줄 = 상자 1개
  - 서버 장부(line_flow.py)가 상자 일정을 한 번만 계산 → 디지털 트윈 · 관제 대시보드 공정 라인 · 생산 관리 트럭이
    같은 순간 같은 상자 번호(#id) · 같은 팔레트 · 같은 트럭 · 같은 LOT
  - 검사기 앞 회색 상자 = 예상 상자(번호 없음), 검사기 지나면 실제 기록 번호
  - 불량: 그 기록의 상자가 빨갛게 → 분기 → 불량함 +1 (세 화면 같은 숫자)
  - 정지(컨베이어 정지): 라인 시계가 멈춤 → 상자가 그 자리에 정지, 재가동하면 이어서
  - 기록이 몰리면 로봇 앞에 줄 섬 → 3개 이상이면 로봇 ×2 '적체 해소' (순간이동 없음)
  - 시연 '트럭 출발' = 라인 빨리감기 ×8 → 실제로 채우고 출발 후 ×1 복귀
  - 생산 관리 '지금 적재 중인 트럭' = 장부 기준 (트럭이 실제 출발하는 순간 새 LOT). 오늘 합계 · 이력은 DB 그대로
  - 새 파일: line_flow.py, static/flow.js  (주소 /api/line/flow)
  - 예전 방식으로 되돌리기: config.py에  FLOW_V2 = False  한 줄 → 서버 재시작
  - 이번에 바꾼 파일 백업: backups/*.1007flow
